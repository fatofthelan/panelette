# Fonts

Panelette's on-device UI is drawn with anti-aliased TFT_eSPI `.vlw`
smooth-fonts. The files `src/NotoSansB18.h`, `src/NotoSansB30.h`,
`src/PlexMono16.h` and `src/PlexMono26.h` are **subsets** (printable ASCII
`0x20`–`0x7E` plus `0xB0`, the degree sign) generated by
`tools/ttf2vlw.py` from the following fonts:

| Bundled file(s) | Source font | Copyright | License |
|---|---|---|---|
| `NotoSansB18.h`, `NotoSansB30.h` | **Noto Sans** (Bold) | © The Noto Project Authors | SIL OFL 1.1 |
| `PlexMono16.h`, `PlexMono26.h` | **IBM Plex Mono** (Medium) | © 2017 IBM Corp. | SIL OFL 1.1 |

Authoritative copies of each font, with their exact copyright headers and
any Reserved Font Names, live upstream:

- Noto Sans — https://github.com/notofonts/latin-greek-cyrillic
  (also https://fonts.google.com/noto/specimen/Noto+Sans)
- IBM Plex — https://github.com/IBM/plex

The full text of the SIL Open Font License 1.1 is in
[`licenses/OFL-1.1.txt`](licenses/OFL-1.1.txt).

## Notes for anyone regenerating or extending these

- These `.vlw` blobs are firmware assets, not installable/redistributable
  font files. They cannot be selected as a system font by any name.
- The SIL OFL reserves the *primary font name as presented to users*. If
  you produce a font file (as opposed to an embedded subset) from these
  sources, do **not** ship it under the names "Noto" or "IBM Plex" / "Plex".
- To rebuild: `python3 tools/ttf2vlw.py <font.ttf> <out.vlw> <px> [weight]`,
  then hexdump the `.vlw` into a `const uint8_t NAME_vlw[] PROGMEM` array.
  `tools/ttf2vlw.py` needs `freetype-py`.
